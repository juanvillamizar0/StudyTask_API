\# StudyTask API



StudyTask API is a web application developed using FastAPI as part of a Web Engineering course.



\## Project Objective



The purpose of this API is to manage academic tasks through three main entities:



\- Students

\- Subjects

\- Tasks



Each task is associated with a student and a subject, allowing tracking of academic activities.



\## Functionality



The API implements the FUCK logic:



\- Find

\- Update

\- Create

\- Kill



\## Technologies



\- Python

\- FastAPI

\- Pydantic

\- CSV (for persistence)

\- Pytest

\- Git \& GitHub



\## MVP Description



This first version allows:



\- Creating students

\- Creating subjects

\- Creating tasks

\- Linking tasks to students and subjects



Future versions may include authentication and database integration.
